# ⚡ Einmaleins Arcade

Ein modernes, rasantes Mathe-Lernspiel für Kinder, um spielerisch das kleine Einmaleins zu verinnerlichen und zu automatisieren.

Entwickelt für **PC (Tastatur/Maus)** sowie **Tablets & Smartphones (Touch)** – läuft direkt im Webbrowser, benötigt keine Installation und funktioniert dank PWA-Technologie auch **100 % offline**.

---

## 🎮 Spielmodi

1. **📚 Lernmodus (Training)**
   * Freie Auswahl der Einmaleins-Reihen (z. B. gezielt nur die 7er- und 8er-Reihe üben).
   * Optional mit oder ohne entspannten Timer.
   * **Kein Game Over bei Fehlern:** Sofortiges, freundliches Feedback mit der korrekten Lösung.

2. **🟢 Arcade: Leicht (4er-Auswahl)**
   * Multiple-Choice mit 4 großen Antwort-Karten zum Antippen.
   * Timer läuft ab – jede richtige Antwort bringt einen Punkt zur Serie (Streak).
   * **Sudden Death:** Falsche Antwort oder Zeitablauf = Game Over!

3. **🟡 Arcade: Normal (Ziffernfeld)**
   * Integriertes Arcade-Numpad (0–9, Löschen, Bestätigen mit ✓) oder echte PC-Tastatur / Numpad.
   * Korrektur von Vertippern möglich, solange der Timer läuft.
   * Timer verkürzt sich alle 5 Aufgaben schrittweise bis auf das einstellbare Cut-Off-Limit (z. B. 2,5 s).

4. **🔥 Arcade: Hardcore (Kein Limit!)**
   * Für echte Profis: Der Timer sinkt unbarmherzig immer weiter ab (bis unter 0,8 s) bis an die Grenze menschlicher Reflexe!

---

## 🏆 Features

* **Arcade-Bestenliste:** Lokale Top-10-Rangliste mit Namenseingabe für die Modi Leicht, Normal und Hardcore.
* **Modernes Design:** Knallige Neon-Farben, abgerundete Karten, animierter Farbbalken-Timer und Partikeleffekte (Konfetti/Sterne bei Rekorden).
* **Synthetisiertes Audio:** Belohnende Chimes, Ticken bei Zeitnot, Game-Over-Jingle und dezent grooviger Synth-Beat (alles rein per Web Audio API generiert, keine externen MP3-Dateien).
* **Einstellungsmenü (⚙️):** Start-Zeitlimit, Minimalzeit, Beschleunigungskurve und Lautstärken können direkt im Spiel angepasst werden.

## 🚀 So startest du das Spiel

### 1. Am Windows-PC
* Öffne einfach die Datei `index.html` per Doppelklick in deinem Webbrowser (z. B. Microsoft Edge oder Google Chrome).

### 2. Auf dem Android-Tablet oder Smartphone
* **Über GitHub Pages (Überall verfügbar, auch bei Oma):**
  1. Lade das Projekt auf dein GitHub-Konto hoch.
  2. Gehe in den Repository-Einstellungen auf **Pages** und aktiviere Branch `main`.
  3. Öffne den Link einmal auf dem Tablet.
  4. Tippe im Browser-Menü auf **„Zum Startbildschirm hinzufügen“** (oder auf das Installations-Symbol).
  5. Das Spiel liegt nun als vollwertige App auf dem Homescreen und funktioniert **auch ohne Internetverbindung**!
